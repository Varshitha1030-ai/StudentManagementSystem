Student Management System

Project Description

The Student Management System is a console-based Java application used to manage student records. It allows users to add, view, search, update and delete student information.

Features

* Add student records
* View all students
* Search students by ID
* Update student details
* Delete student records
* Display unique courses
* Count student records
* Save and retrieve records using file handling
* Validate user input
* Automatically save records in the background

Technologies Used

* Java
* Eclipse IDE
* Git
* GitHub

Java Concepts Used

* Object-Oriented Programming
* Classes and Objects
* Constructors and this
* Inheritance and Polymorphism
* Encapsulation and Abstraction
* Interfaces
* Exception Handling
* ArrayList, HashMap and HashSet
* File Handling
* Multithreading

Project Structure

* Person.java — Abstract parent class
* Student.java — Student details and file conversion
* StudentOperations.java — Application interface
* StudentManager.java — Record management and persistence
* Main.java — Menu-driven application

How to Run the Project

1. Install a compatible JDK and Eclipse IDE.
2. Import or create the Java project in Eclipse.
3. Place all five Java files in the studentmanagement package.
4. Open Main.java.
5. Select Run As → Java Application.
6. Use the Console menu to manage student records.
